# Folder Audio ZiuLabs

Simpan file rekaman audio custom Anda di folder ini:

- **Nama file utama:** `mascot-voice.mp3`
- **Format yang didukung:** `.mp3` (disarankan), `.wav`, `.m4a`
- **Durasi ideal:** 1 - 3 detik (misal: "Saya akan lawan!" atau sound effect robot)
- **Ukuran ideal:** < 100 KB agar instan saat dimainkan di HP & browser pengguna.

Ketika file `mascot-voice.mp3` diletakkan di folder ini, maskot ZiuBot di halaman web akan langsung memutar audio tersebut saat disentuh/di-hover. Jika file belum ada, sistem otomatis menggunakan suara robot sintetis browser.
